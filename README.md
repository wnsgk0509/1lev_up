# 1lev_up (하루 1레벨 업 최소 습관 & 루틴 시스템)

> **"의지력에 기대지 마세요. 시스템이 당신을 자동으로 데려다줍니다."**  
> 《아주 작은 습관의 힘(Atomic Habits)》과 《원씽(The ONE Thing)》의 핵심 원리를 바탕으로, 힘든 날에도 무너지지 않고 지킬 수 있는 최소 기준(Minimum Viable Routine)을 만들어주는 서비스입니다.

---

## 🌟 주요 기능

### 1. 오늘의 One Thing (가장 중요한 일 1가지)
- **전날 밤 작성한 내일의 One Thing 자동 연동**: 아침에 일어났을 때 "오늘 뭐 하지?" 고민하는 인지적 에너지를 0으로 만듭니다.
- **없을 시 독서 15분으로 대체**: 컨디션이 저하되거나 마땅한 일이 없을 때 클릭 한 번으로 독서 15분 루틴으로 대체할 수 있습니다.
- **달성 축하 애니메이션**: 완료 시 콘페티 효과와 함께 성취감을 제공합니다.

### 2. 타임라인 기반 최소 루틴 체크리스트
1. ☀️ **아침 7시 기상** (07:00 AM)
2. 🚶 **아침 15분 산책** (기상 직후 햇빛 쬐기)
3. 🎯 **가장 중요한 일 1가지 수행** (없을 시 독서 15분)
4. 🥗 **점심 15분 산책** (식후 에너지 충전)
5. 💻 **퇴근 후 자기계발 1시간** (60분 몰입 전용 타이머 탑재)
6. 🌙 **오늘 하루 및 독서 기록 + 내일 One Thing 메모** (하루를 닫는 회고 루틴)

### 3. 독서 서재 & 하루 회고 (Reading & Journal Archive)
- **독서 노트**: 읽은 책 제목, 분량, 마음에 와닿은 문장과 나의 인사이트 기록 및 검색
- **하루 회고**: 오늘 하루 기분과 감사한 일, 배운 점
- **내일의 One Thing 정하기**: 취침 전 기록하면 다음 날 화면에 자동 배정

### 4. 지속 가능한 동기부여 시스템
- **연속 달성 스트릭(Streak)** 불꽃 카운터
- **월간 캘린더 달성 현황**: 과거 기록 및 성취도 시각화
- **로컬 저장소 & 데이터 백업**: 로그인 없이 브라우저에 안전 저장되며, 언제든 JSON 파일로 내보내기/가져오기 가능
- **루틴 커스터마이징**: 나만의 루틴 추가/편집 가능

## 🚀 실행 방법

### 로컬 실행
```bash
# 의존성 설치
npm install

# 로컬 개발 서버 실행
npm run dev
```
브라우저에서 `http://127.0.0.1:5173/` 접속

### 모바일에서 앱처럼 사용하는 팁 (스마트폰 홈화면에 추가)
1. 스마트폰 브라우저(Safari 또는 Chrome)에서 해당 페이지에 접속합니다.
2. 브라우저 메뉴의 **[공유]** 또는 **[더보기(점 3개)]** 클릭
3. **[홈 화면에 추가]**를 누르면 스마트폰 바탕화면에 앱 아이콘 형태로 추가되어 네이티브 앱처럼 깔끔하게 사용할 수 있습니다.
